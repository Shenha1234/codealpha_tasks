# CodeAlpha Hotel Reservation System

A Java-based Hotel Reservation System developed as part of the CodeAlpha Java Programming Internship.

## Project Description

This project provides a console-based hotel reservation system for searching available rooms, viewing room categories, booking rooms, cancelling reservations, simulating payments, and viewing booking details.

The project uses Object-Oriented Programming principles to manage rooms, customers, reservations, payments, and hotel operations.

## Features

- View available rooms
- Search rooms
- Standard room category
- Deluxe room category
- Suite room category
- Book hotel rooms
- Cancel reservations
- View booking details
- View all reservations
- Payment simulation
- Cash payment option
- Card payment option
- UPI payment option
- Reservation status management
- Date-based booking
- Input validation and error handling

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Java Date and Time API
- VS Code
- Git
- GitHub
