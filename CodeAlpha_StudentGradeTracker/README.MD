# CodeAlpha Student Grade Tracker

## Project Overview

Student Grade Tracker is a Java-based application developed as part of the CodeAlpha Java Programming Internship.

The application allows users to manage student information and grades, calculate academic performance, and generate a class summary report.

## Features

- Add student
- Add student marks
- Calculate total marks
- Calculate average marks
- Find highest mark
- Find lowest mark
- Calculate grade
- Search student
- Update student
- Delete student
- Class summary report
- GUI using Java Swing
- CSV file data persistence
- Automatic data loading

## Technologies Used

- Java
- Object-Oriented Programming
- Java Swing
- ArrayList
- File I/O
- CSV data storage
